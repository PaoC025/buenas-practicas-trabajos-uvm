# Buenas Prácticas para Trabajos Universitarios en Grupo

Manual colaborativo desarrollado en el marco del Diplomado en Ciberseguridad (UVM),
como práctica de uso de Git y GitHub para control de versiones en documentos.

## 🎯 Objetivo
Recopilar buenas prácticas para el desarrollo de trabajos universitarios en grupo:
organización, gestión de tiempos, formatos, citación y presentación.

## 📁 Estructura del repositorio
- `/documentos` → secciones del manual en Markdown/Word
- `/imagenes` → recursos gráficos usados en el manual
- `/referencias` → fuentes y bibliografía de apoyo
